# Natural langauge processing using python
## Do the following steps to run the code in your machine:
1. clone this project
   `git clone git@github.com:1nuc/nlp-python-project.git`
2. navigate to that project
   `cd nlp-python-project`
3. create a python virtual environment or activate your current one
   for a new one do:
   `python -m venv env`
   then activate it with
   `source env/bin/activate`
   or if you already have one
   `source your_env_name/bin/activate`
4. Download the essential libraries
   `pip install nltk pydantic spacy textblob`
5. Head Over to the code inside the source directory and run the cells and your good to go
